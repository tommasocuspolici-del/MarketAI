# MarketAI Vault - Guida Rapida

Questo vault è stato generato per supportare lo sviluppo e la documentazione del progetto MarketAI.

## Struttura delle Cartelle
- **00 - Index**: Note di benvenuto e indice.
- **01 - Architecture**: Documentazione architetturale di alto livello.
- **02 - Engine Layer**: Tutti i moduli del motore di analisi.
- **03 - Personal Layer**: Moduli per la gestione finanziaria personale.
- **04 - Shared Layer**: Componenti condivisi (DB, cache, monitoring, resilience).
- **05 - Bridge**: Strati di comunicazione tra Engine e Personal.
- **06 - Presentation (UI)**: Dashboard e componenti UI (Streamlit).
- **07 - Configuration**: File di configurazione YAML.
- **08 - Scripts**: Script di utilità (setup, backup, scheduler, QA).
- **09 - Custom Indicators**: Framework per indicatori personalizzati e DSL.
- **10 - Database**: Schema e migrazioni del database.
- **11 - Roadmap**: Piani di sviluppo e miglioramento.
- **12 - Glossary**: Glossario dei termini tecnici.
- **13 - Changelog**: Cronologia delle modifiche.

## Convenzioni di Naming
- I nomi dei file usano il **Pascal Case** con spazi (es. `Engine Overview.md`).
- I tag seguono il formato `#MarketAI #Componente #Modulo`.
- I link interni usano il doppio bracket `[[Nome Nota]]`.
